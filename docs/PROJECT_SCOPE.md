# Project Scope

This portfolio project demonstrates the core architecture requested by a stablecoin merchant payment platform.

## MVP capabilities

- Merchant registration
- Customer ERC-20 approval and payment
- Payment replay protection
- Merchant balance accounting
- Controlled settlement
- On-chain events for indexing
- Role-based privileged operations
- Local Hardhat test environment

## Next implementation layers

1. TypeScript payment-intent API
2. Event indexer and transaction status service
3. Next.js merchant/customer UI
4. MetaMask and WalletConnect integration
5. Testnet deployment
6. End-to-end tests
7. Production hardening and audit preparation
